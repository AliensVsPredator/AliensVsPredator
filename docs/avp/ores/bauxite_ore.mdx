## Description
Bauxite is the ore form of [Aluminum](../items/aluminum_ingot) and when mined drops [Raw Bauxite](../items/raw_bauxite). This a key ingredient for several blocks and upgraded materials.

### Generation
Bauxite can be found throughout the world above Y=0 however it is more concentrated the higher up you go so high mountains are a very good source for this ore.

### Smelting
Bauxite ore can be cooked in a furnace or quicker in a blast furnace.
