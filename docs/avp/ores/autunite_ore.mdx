## Description
Autunite is a unique ore with radioactive properties it can be found inside of [Autunite Geodes](../structures/autunite_geode) spread throughout the world. It can be mined in order to obtain [Autunite Dust](../items/autunite_dust).

### Behavior
Unlike other ores autunite is dangerous to handle. It gives off [Radiation](../mechanics/radiation) and if touched will make the player [Sick](../effects/radiation_sickness).

### Generation
Autunite can be found inside of autunite geodes in small groups. These geodes spawn in the world in all biomes between Y=6-30.
